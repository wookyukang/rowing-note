# 로잉노트

조정팀용 훈련 기록 웹앱이에요. 에르고·수상·바이크·서킷 기록, 존2 가이드, 훈련 계획과 프로그램, 개인 기록, 팀 보드, 크루 구성을 한 곳에서 관리해요.

- 화면: `index.html` 하나 (빌드 과정 없음)
- 데이터·로그인: [Supabase](https://supabase.com) (무료 요금제로 충분)
- 배포: [Vercel](https://vercel.com) (무료)

## 처음 설정하기

### 1. Supabase 프로젝트 만들기
1. supabase.com 로그인 → **New project**
2. 이름: `rowing-note`, 데이터베이스 비밀번호는 아무거나 길게(따로 적어두기), Region은 **Northeast Asia (Seoul)**
3. 만들어질 때까지 1–2분 기다리기

### 2. 데이터베이스 만들기
1. 왼쪽 메뉴 **SQL Editor** → **New query**
2. 이 저장소의 `supabase/schema.sql` 내용을 전부 복사해서 붙여넣기 → **Run**
3. 아래쪽에 `Success. No rows returned` 가 나오면 성공

### 3. 이메일 확인 끄기 (중요)
이 앱은 이메일 대신 아이디로 가입해요. 그래서 이메일 확인을 꺼야 해요.
1. 왼쪽 메뉴 **Authentication** → **Sign In / Providers** (또는 Providers) → **Email**
2. **Confirm email** 끄기 → 저장

### 4. 연결 정보 넣기
1. **Project Settings** → **API** (또는 Data API / API Keys)
2. **Project URL** 과 **anon public** 키를 복사
3. `config.js` 의 `url`, `anonKey` 에 붙여넣기
   - `service_role` 키는 절대 넣지 마세요.

### 5. Vercel로 배포
1. vercel.com 에 GitHub 계정으로 로그인
2. **Add New… → Project** → `rowing-note` 저장소 **Import**
3. 설정은 그대로 두고 **Deploy**
4. 나온 주소(예: `rowing-note.vercel.app`)를 팀에 공유

이후 GitHub에 코드가 올라갈 때마다 Vercel이 자동으로 다시 배포해요.

## 사용 방법

1. **코치**: 가입 → "새 팀 만들기" → 팀 이름 입력. 화면 위에 **선수 코드**와 **코치 코드**가 나와요.
2. **선수**: 가입 → "팀 코드로 가입" → 선수 코드 입력.
3. 다른 코치: 코치 코드로 가입하면 코치 권한을 받아요.
4. 휴대폰에서 앱처럼 쓰기: 사이트를 연 뒤
   - 아이폰(사파리): 공유 버튼 → **홈 화면에 추가**
   - 안드로이드(크롬): 메뉴 ⋮ → **홈 화면에 추가**

### 권한
| | 코치 | 선수 |
|---|---|---|
| 기록 저장 | 모든 선수 | 본인만 |
| 기록 삭제 | 전부 | 본인이 쓴 것만 |
| 선수 추가 | O | X (코드로 가입하면 자동 등록) |
| 훈련 계획·프로그램 | 올리기·삭제 | 보기·기록하기 |
| 최대 심박·체급 설정 | 모든 선수 | 본인만 |

### 알아둘 점
- 선수가 직접 가입하면 선수 명단에 자동으로 들어가요. 코치가 "+ 선수 추가"로 같은 선수를 미리 넣으면 두 번 보일 수 있어요. 계정 없는 선수만 코치가 추가하세요.
- 아이디/비밀번호를 잊으면 Supabase 대시보드 **Authentication → Users** 에서 해당 사용자(`아이디@rowingnote.app`)를 지우고 다시 가입해야 해요. 이때 그 선수의 팀 가입도 다시 해야 해요.
- 훈련 템플릿과 존·페이스 기준은 일반적인 조정 훈련 원칙으로 만든 참고값이에요. 실제 훈련은 코치 판단을 따르세요.
- Claude 아티팩트 버전에 있던 "모니터 사진 자동 입력"은 AI API 비용이 들어서 이 버전에는 빠져 있어요.
